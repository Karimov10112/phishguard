POST /api/v1/analyze — xatni to‘liq tahlil qilish

JSON: raw (to‘liq MIME xat) yoki text + ixtiyoriy subject, sender. Multipart: file (.eml).

curl -X POST {{ request.host_url }}api/v1/analyze \
  -H "Content-Type: application/json" \
  -d '{"text": "Your account has been suspended. Verify within 24 hours: http://paypal-verify.xyz/login",
       "subject": "Security alert", "sender": "PayPal <service@paypa1.com>"}'
curl -X POST {{ request.host_url }}api/v1/analyze -F "file=@xat.eml"

POST /api/v1/score — komponentlardan Risk Score hisoblash

Diplom ishidagi 3.1-band namunasi: komponent ballari tashqi modullardan keladi.

curl -X POST {{ request.host_url }}api/v1/score -H "Content-Type: application/json" \
  -d '{"message_id": "<20260311.abc@mail.example.com>", "p_ml": 0.78, "p_bert": 0.92, "s_domain": 0.70, "s_url": 0.00}'

200 OK
{"message_id": "<20260311.abc@mail.example.com>", "risk_score": 0.7, "verdict": "PHISHING", "action": "block_and_notify_soc"}
